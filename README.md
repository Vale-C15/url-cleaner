# URL Cleaner ✦

<p align="center">
  A simple way to keep your links clean.
</p>

---

A lightweight Python script that removes unnecessary tracking parameters from URLs while keeping the original destination intact.

Useful when saving, sharing or organizing links from social media.

## ✧ Supported platforms

- LinkedIn
- Instagram
- Facebook
- Pinterest
- YouTube
- TikTok
- X (Twitter)

## ✧ Features

- Removes common tracking parameters (UTM, referral and sharing data).
- Applies platform-specific cleaning rules.
- Preserves important parameters required for the link to work.
- Accepts multiple URLs in one session.
- Runs directly from the terminal.

## ✧ Getting started

**Requirements:** Python 3 installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/Vale-C15/url-cleaner.git
   ```

2. Open the project folder:

   ```bash
   cd url-cleaner
   ```

3. Run the script:

   ```bash
   python YOUR_SCRIPT_NAME.py
   ```

4. Paste a URL and get its cleaned version.

Type `salir` to close the program.

## ✧ Example

**Before**
```text
https://www.linkedin.com/posts/example?rcm=tracking_data
```

**After**
```text
https://www.linkedin.com/posts/example
```
